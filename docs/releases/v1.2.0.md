Windows x64 release with the new image-to-3D asset workbench.

- Create separate asset versions from reference images through a local Hunyuan3D 2.1 backend.
- Import self-contained GLBs, inspect UVs and texture/material data, and export the original model.
- Prepare editable Blender scenes with packed textures, a camera, and studio lighting.
- Fix embedded textures appearing white in the 3D viewport, improve framing and PBR lighting, and inspect assets from underneath.
- Bundle the backend scripts and GPU setup guide; open them from Assets → Generation server.

Install Blender 4.2+ separately. Configure chat-model credentials in Providers for the world-script agent. Image-to-3D generation additionally requires Python, the upstream Hunyuan runtime and model weights, and a compatible NVIDIA GPU; these large dependencies are not bundled.

The new neural-generation integration is experimental. GPU inference, output quality, and CPU offloading have not yet been validated on an RTX 5060 Ti. Its 16 GB VRAM is below Hunyuan3D 2.1's documented texture-stage requirement; start with Balanced/offload mode and follow the bundled guide. This release does not claim Meshy parity.

The installer is unsigned. Download `GameCreator-Prime-1.2.0-setup.exe` and verify it against `SHA256SUMS.txt`. The repository license is unchanged.
